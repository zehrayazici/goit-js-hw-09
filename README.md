# goit-js-hw-09 - Image Gallery & Feedback Form

JavaScript homework project featuring an image gallery with SimpleLightbox and a form with localStorage integration.

### Task 1 - Image Gallery
- Dynamic gallery using SimpleLightbox library
- Modal window with 250ms caption delay
- Keyboard navigation support

### Task 2 - Feedback Form
- Real-time localStorage saving
- Auto-restore on page reload
- Form validation before submit
- Auto-clear after successful submission

##  Technologies

- HTML5, CSS3, JavaScript (ES6+)
- Vite
- SimpleLightbox
